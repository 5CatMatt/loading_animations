# Loading Bar Assets

![Advent of Code Banner](https://adventofcode.com/static/logo.png)

Welcome to the **Loading Animation** repository! 🎄✨

## 🚀 Overview
This is a loading bar toy to spice up long running loops in a terminal. great for the [Advent of Code](https://adventofcode.com/) puzzles.

## 📂 Project Structure
```
example.py              # Example use
loading_animations.py   # Fun loading animations for CLI
```

## 🛠️ Usage
1. Clone the repo:
   ```powershell
   git clone https://github.com/5CatMatt/loading_animations.git
   ```
2. Run an example:
   ```powershell
   python example.py
   ```

## ✨ Features
- **Reusable Animations**: Spice up your CLI with `loading_animations.py`.
- **Clean Templates**: Start your puzzle solutions quickly.
- **Easy to Extend**: Add your own scripts and assets!

## 📦 Requirements
- Python 3.11+
